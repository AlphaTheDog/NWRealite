# NWRealite
Contains implementation for a potential test Interview I was to participate in.

Overview
This project analyzes lease data to make property management easier and more actionable. It consolidates information from leases, units, properties, and locations to calculate key metrics like lease duration, rent paid, and arrears.

Features

Categorizes leases as Ongoing, Expired, or Invalid

Calculates lease duration in months

Aggregates rent and arrears by tenant, property, or location

Basic visualizations for quick insights

Tech Used

Python (pandas, matplotlib)
